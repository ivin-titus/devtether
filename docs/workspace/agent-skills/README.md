# DevTether Agent Skills

Project-specific Agent Skills for DevTether.

These skills contain procedural workflows only. Project facts and engineering rules remain in their existing canonical documents.

## Skills

### `devtether-change`

Use for implementation work.

Covers:

* release/workspace context;
* pre-mortem;
* plan updates;
* separated implementation;
* independent verification;
* human approval;
* Git planning.

### `devtether-audit`

Use for independent review.

Covers:

* correctness;
* regressions;
* dependency impact;
* architecture/ADR compliance;
* engineering-standard compliance;
* test adequacy;
* workspace/documentation consistency.

## Canonical project documentation

Start with:

`../../workspace/README.md`

Then follow the relevant release workspace and its linked technical documentation.

Do not copy project documentation into these skills.
